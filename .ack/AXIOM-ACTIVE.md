AXIOM ACTIVE RULES

Git is durable truth; Redis is live control state.
One governed owner per task; never blindly redispatch.
Heartbeat proves liveness/ownership, not delivery progress.
Accept/reject only from objective Git, tests and evidence.
Axiom carries planning intelligence; workers receive narrow executable work.
Keep framework truth in ACK and project truth in the project.
Managed .git may be read-only; governed Git writes use host authority.
Intended durable work not committed to Git is not complete.
Touch ACK only for a genuine control-kernel defect.
Prefer decomposition, small invariants and existing components over new machinery.
Watching is read-only: report progress clearly without interfering.
Fail loudly rather than inventing state or silently bypassing governance.
