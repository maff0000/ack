# Project Essentials — customise when copied

- ACK source root for this project is `/srv/codex/ACK`.
- ACK is portable; every adopting project defines its own explicit `PROJECT_ROOT` in `PID.md`.
- Workers may never mutate outside the canonical project root.
- Git is durable truth; Redis is live operational state.
- Axiom alone accepts or rejects work and integrates canonical changes.
- Keep the framework lightweight; do not recreate PBGv2-style bureaucracy.
